# [PROUESTA] Guía para Consultar la Base de Datos (Diátaxis How-to)

Esta guía describe cómo conectarse y realizar consultas básicas en la base de datos de TienditaCampus.

## Estructura Propuesta

### 1. Prerrequisitos
- Instalación de Docker (local).
- Cliente SQL (DBeaver, pgAdmin o psql).

### 2. Conexión Local (Docker)
- Comandos `docker exec`.
- Configuración en herramientas externas.

### 3. Conexión Remota (AWS Production)
- Parámetros de conexión (IP, Usuario, Puerto).
- Seguridad de la contraseña.

### 4. Comandos de Consulta Básicos
- Listar tablas.
- Consultas SELECT comunes (Usuarios, Productos).
- Visualización de la vista consolidada de ventas.

### 5. Resolución de Problemas (Troubleshooting)
- Errores de conexión comunes.
- Verificación de estado del contenedor.
